# Intro
This is the frontend-specific Agents file. These are rules to follow when writing the frontend.

# Code cleanliness
The code you write must be modular. If there is code that can be reused, then reuse it, and always remember the DRY principle: Don't Repeat Yourself.
If you are at a crossroads between writing a shorter, more complicated and a longer less complicated function, choose the less complicated version. always go for the least amount of complexity.

# User Experience
The user experience of this application should be the utmost priority. The easier you can make an action, the better.

The smoother you can make a UI component feel, the better. But keep in mind, don't overdo it by making the UI too flashy that the user forgets the main purpose of this application.
